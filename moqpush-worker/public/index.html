Getting Started
Start streaming in minutes

Sign in and create a namespace

Go to the Dashboard and sign in with Google or Discord. Create a namespace (e.g. my-stream) and select which regions to pre-position into. Your Push Key will be generated automatically — click it to copy.

Build and run moqpush-app

Clone the repo and build the publisher binary:

# Build the publisher
cargo build --release -p moqpush-app

# Run it with your Push Key
./target/release/moqpush-app \
  --push-key mpk_YOUR_PUSH_KEY_HERE \
  --port 9078

The app will authenticate with moqpush.com, get the relay URL for your namespace, and start listening for CMAF-IF ingest on the specified port.

Point your encoder

Configure your encoder (e.g. Ateme Titan Live, FFmpeg, OBS with CMAF output) to push CMAF-IF segments via HTTP PUT to:

http://localhost:9078

Once the first init segment arrives, moqpush-app connects to the Cloudflare MoQ relay and begins publishing. Your configured edge servers will automatically start pulling to warm the network.

Share the playback link

Your stream is live! Share the link with anyone:

https://moqpush.com/my-stream

Viewers get sub-second latency playback via Shaka Player and WebTransport — no plugins, no apps, just a browser.

Features
Built for live production

Global Pre-positioning

Edge servers in 5 regions pull your stream through Cloudflare, warming the network before viewers connect.

Ultra-low Latency

MoQ Transport (draft-14) over QUIC/WebTransport delivers sub-second glass-to-glass latency.

Simple Ingest

Standard DASH-IF CMAF ingest over HTTP PUT — works with any encoder supporting the spec.

Real-time Stats

Live publisher and player metrics, per-region warm status, and WebSocket-driven dashboards.

One-click Sharing

Share a link like moqpush.com/your-stream and anyone can watch instantly in their browser.

Cloudflare Powered

Worker + Durable Objects handle auth, orchestration, and stats. Scales automatically.
